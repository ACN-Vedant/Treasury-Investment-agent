6-Agent Treasury Analysis Pipeline

Agent 1: Reporting Agent

Analyzes cash balances, bank statements, loan schedule, and existing investments. Calculates net investable surplus after applying manual haircut. Outputs recommended investable amount per account with trend classification.

Agent 2: Ratings Agent

Validates counterparty credit ratings against policy minimum. Assesses creditworthiness for each potential investment opportunity. Flags positions below minimum rating threshold.

Agent 3: Compliance Agent

Verifies all positions comply with treasury policy: maximum tenor (days), minimum credit rating, approved product types. Marks compliant vs non-compliant positions.

Agent 4: Opportunity Agent

Recommends investment allocations ranked by yield and risk. Incorporates loan-constrained tenor limits. Provides portfolio composition breakdown. Passes recommendations to Trader Agent.

Agent 5: Trader Agent

Structures deal terms from counterparty confirmation. Creates TMS deal record. Performs loan maturity cross-check to ensure funds available for debt service. Flags discrepancies for review.

Agent 6: Deal Approval Agent

Final 7-point validation: notional amount, currency, counterparty, dates, yield, loan constraint. Returns APPROVED or REQUIRES_REVIEW status with full audit trail.
